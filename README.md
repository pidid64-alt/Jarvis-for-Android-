# 🤖 J.A.R.V.I.S. для Android

Голосовой ассистент в стиле Железного человека: wake-word «Джарвис», офлайн-управление
телефоном, чат с большой языковой моделью и озвучка ответов. Всё на русском.
Провайдера ИИ выбираете сами: Gemini, OpenAI, OpenRouter, DeepSeek, Groq,
Mistral, Together, Claude или локальная Ollama.

![Скриншот-идея](icon_master.png)

## 🆕 Что нового в 2.3

- **Шумоподавление микрофона.** Джарвис включает системные эффекты микрофона —
  шумоподавление, эхоподавление (чтобы не слышал собственный голос из динамика)
  и автоусиление речи — и лучше разбирает команды в шумном месте. Управление:
  настройка ⚙ → «Шумоподавление микрофона» или голосом — «включи/выключи
  шумоподавление», «шумоподавление включено?». В настройках видно, что реально
  умеет прошивка: если телефон не отдаёт аппаратных эффектов, Джарвис честно
  об этом скажет.
- **Микрофон больше не «сбрасывается».** Фоновое прослушивание стало
  самовосстанавливающимся:
  - перезапуски распознавания «гоняются по поколениям» — отложенные циклы больше
    не накапливаются и не создают залпом десятки распознавателей после закрытия
    окна приложения (это и была главная причина сбоев);
  - при открытии окна приложения фоновая служба **сразу освобождает микрофон** —
    два распознавателя больше не дерутся за него;
  - если микрофон перехватило другое приложение или аудиотракт перезапустился,
    служба переподключается с нарастающей паузой и пишет в уведомлении
    «Микрофон сбрасывался — перезапускаю…», а после возврата — «снова в строю»;
  - «молчаливые» смерти распознавателя (без ошибок) ловит watchdog;
  - выключенный системно микрофон замечается сразу («Микрофон выключен в системе»);
  - в окне приложения при техническом сбое микрофона слушание тихо
    переподключается само (до двух попыток), без красных тостов.
- **Попутно починено**: закрытие окна приложения больше не воскрешало
  фоновое прослушивание, если вы его выключили командой «выключи джарвиса».
- **Тестов больше**: `scripts/test-commands.sh` — 58 проверок (в том числе
  разбор голосовых команд шумоподавления).

## 🎙 Работа без приложения

1. Включите тумблер **«Служба „Джарвис"»** (включён по умолчанию) — появится
   постоянное уведомление «Джарвис на связи».
2. Скажите **«Джарвис»** — прозвучит сигнал, телефон вибрирует, поверх экрана
   появится сфера.
3. Произнесите команду — Джарвис выполнит её и ответит голосом. Приложение при
   этом открывать **не нужно**.
4. Если команда требует экрана (звонок, запуск чужого приложения) — окно откроется
   само, но только при включённом разрешении «Показ поверх других окон».

**Настройки ⚙ → «Чтобы работало без приложения»** — чек-лист из шести пунктов:
ожидание слова, микрофон, уведомления, поверх других окон, без ограничений батареи,
точные напоминания. Зелёные галочки = всё готово.

### Честно об ограничениях Android

- **Android 14+** запрещает запускать микрофон-службу из фона, в том числе по
  `BOOT_COMPLETED`. Поэтому **после перезагрузки** приходит уведомление
  «Джарвис не слушает — нажмите, чтобы включить»: одно нажатие открывает окно,
  и служба запускается уже легально.
- Без разрешения **«Показ поверх других окон»** Android 10+ не даст открыть окно
  (звонок, YouTube) из закрытого приложения — голосовые ответы при этом работают.
- Без **«Не ограничивать работу в фоне»** прошивки (Xiaomi, Samsung, Huawei)
  выгружают службу через несколько минут.
- Wake-служба использует системный `SpeechRecognizer`: на устройствах без сервиса
  распознавания речи (без Google-приложения) она работать не будет — в уведомлении
  появится соответствующая надпись.

## 📲 Установка

1. Скачайте APK из этого репозитория:
   **[releases/Jarvis-v2.2.apk](releases/Jarvis-v2.2.apk)**
   (на странице файла нажмите «Download raw file»).
2. Разрешите установку из неизвестных источников.
   > Ставите поверх старой версии и видите «подписи не совпадают»? Удалите старую —
   > debug-ключ (`keystore/`) в Git не хранится и создаётся заново при сборке.
3. При первом запуске дайте разрешения: **микрофон** (обязательно), уведомления,
   контакты (для «позвони…»).
4. Настройки ⚙ → раздел **«Чтобы работало без приложения»** → выдайте три разрешения.
5. Настройки ⚙ → **Провайдер ИИ** → выберите провайдера, вставьте ключ и модель
   → «Проверить ключ» (нужно только для свободных вопросов; офлайн-команды
   работают без всяких ключей).
6. Готово: скажите «Джарвис» или нажмите на сферу-реактор 💠 в приложении.

> Приложение не собирает и не отправляет ничего, кроме текста ваших запросов —
> и только тому провайдеру, которого вы выбрали сами. Ключи хранятся в
> `SharedPreferences` на телефоне и никуда не уходят.

## 🛠 Сборка из исходников

### Способ 1 — оффлайн-скрипт (без Gradle и Android SDK)
Тулчейн (JDK, build-tools, android.jar, kotlin-compiler) качается из публичных
Git-зеркал AOSP — работает даже там, где Maven Central заблокирован:

```bash
scripts/fetch-toolchain.sh   # один раз, нужно право писать в /opt
scripts/build-apk.sh         # соберёт releases/Jarvis-v<версия>.apk
scripts/test-logic.sh        # 165 проверок чистой логики (быстро)
scripts/test-commands.sh     # 51 проверка диспетчера команд (компилирует всё приложение)
```

Пайплайн: `aapt2 compile/link → kotlinc → d8 (+ kotlin-stdlib) → zipalign → apksigner`.
Подпись: самоподписанный debug-ключ `keystore/jarvis.jks` (создаётся автоматически,
пароль `jarvis25`). Для публикации замените на свой ключ!

`scripts/test-logic.sh` компилирует **те же самые файлы**, что попадают в APK
(`MathEngine.kt`, `WakeWords.kt`, `TimeParse.kt`, `Timezones.kt`, `Units.kt`,
`LifeCalc.kt`, `DateFacts.kt`, `TextTools.kt`, `Randoms.kt`), и прогоняет их на
обычной JVM — эмулятор не нужен.

`scripts/test-commands.sh` идёт дальше: компилирует **всё приложение** (с
автогенерацией R-класса через aapt2) и дёргает настоящий `CommandEngine.execute()`
на JVM с Context-«пустышкой». Так проверяется порядок разделов — например, что
«раздели 100 на 4» остаётся арифметикой, а «раздели 9000 на троих» делит счёт.

### Способ 2 — Android Studio / Gradle
Проект обычный: `app/`, `compileSdk 34`, `minSdk 26`, Kotlin, **нулевые зависимости**.
```bash
./gradlew assembleDebug   # или откройте папку в Android Studio
```
> Если ваш AGP ругается на `package=` в манифесте — удалите эту строку
> (namespace уже задан в `app/build.gradle.kts`). Оффлайн-скрипту она нужна.

## ⚠️ Замечания

- Требуется Android **8.0+** (API 26). Проверено на targetSdk 34.
- Курсы валют и погода требуют интернет; курсы обновляются сервисом раз в сутки.
- «Яркость 40 процентов» попросит разрешение «изменять системные настройки»
  (Android не даёт менять яркость без него) — выдаётся одним нажатием.
- «Кто звонил последним» и «какой у меня номер» работают только после выдачи
  соответствующих разрешений.
- Постоянное прослушивание микрофона расходует батарею — скажите
  **«Джарвис, спи 60 минут»** или выключите тумблер.
- На некоторых прошивках сервис распознавания недоступен — тогда отключите
  wake-службу (иконка 🎙 в шапке) и пользуйтесь окном.

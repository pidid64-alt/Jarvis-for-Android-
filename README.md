# 🤖 J.A.R.V.I.S. для Android

Голосовой ассистент в стиле Железного человека: wake-word «Джарвис», офлайн-управление
телефоном, чат с Google Gemini и озвучка ответов. Всё на русском.

![Скриншот-идея](icon_master.png)

## ✨ Что умеет

### Работает без интернета (мгновенно)
| Команда | Действие |
|---|---|
| «включи / выключи **фонарик**» | Управление вспышкой |
| «**открой** ютуб / телеграм / камеру / …» | Запуск приложений (по имени, с псевдонимами) |
| «**позвони** маме», «**напиши** папе» | Звонок / SMS по контактам |
| «**будильник на 7:30**», «таймер на 5 минут» | Ставит будильник/таймер |
| «**сколько заряда**», «который час», «какое число» | Батарея, время, дата |
| «**маршрут до** дома», «найди пиццу рядом» | Google Maps / поиск |
| «включи музыку», «**громче** / тише», «выключи звук» | Мультимедиа и громкость |
| «включи вайфай», «блютус», «авиарежим» | Панели сетевых настроек |
| «найди / загугли …», «… на ютубе» | Поиск в интернете / YouTube |
| «повтори», «стоп», «что ты умеешь» | Служебное |

### Через Gemini (нужен бесплатный API-ключ)
Любые вопросы и беседа — контекст диалога сохраняется, ответы озвучиваются.
Получить ключ бесплатно: **https://aistudio.google.com/apikey**

### Голосовая активация
Фоновая служба непрерывно слушает микрофон: скажите **«Джарвис»** — ассистент
проснётся (звук + вибро), откроется и сразу начнёт слушать команду.

## 📲 Установка

1. Скачайте `Jarvis-v1.0.apk` со страницы [Releases](../../releases).
2. Разрешите установку из неизвестных источников.
3. При первом запуске дайте разрешения: **микрофон** (обязательно), уведомления (для
   wake-службы), контакты (для «позвони…»).
4. Откройте **Настройки ⚙** → вставьте API-ключ Gemini → «Проверить ключ».
5. Готово. Нажмите на сферу-реактор 💠 или включите иконку микрофона 🎙 в шапке.

> Приложение не собирает и не отправляет ничего, кроме текста ваших запросов в Google
> Gemini. API-ключ хранится только на телефоне.

## 🛠 Сборка из исходников

### Способ 1 — оффлайн-скрипт (без Gradle и Android SDK)
Тулчейн (JDK, build-tools, android.jar, kotlin-compiler) качается из публичных
Git-зеркал AOSP — работает даже там, где Maven Central заблокирован:

```bash
scripts/fetch-toolchain.sh   # один раз, нужно право писать в /opt
scripts/build-apk.sh         # соберёт releases/Jarvis-v1.0.apk
```

Пайплайн: `aapt2 compile/link → kotlinc → d8 (+ kotlin-stdlib) → zipalign → apksigner`.
Подпись: самоподписанный debug-ключ `keystore/jarvis.jks` (создаётся автоматически,
пароль `jarvis25`). Для публикации замените на свой ключ!

### Способ 2 — Android Studio / Gradle
Проект обычный: `app/`, `compileSdk 34`, `minSdk 26`, Kotlin, **нулевые зависимости**.
```bash
./gradlew assembleDebug   # или откройте папку в Android Studio
```
> Если ваш AGP ругается на `package=` в манифесте — удалите эту строку
> (namespace уже задан в `app/build.gradle.kts`). Оффлайн-скрипту она нужна.

## 📁 Структура

```
app/
  AndroidManifest.xml        — разрешения, службы, приёмник BOOT_COMPLETED
  res/                       — ресурсы (тёмная cyan-тема, иконки-векторы, mipmaps)
  src/kz/jarvis/app/
    App.kt                   — Application, канал уведомлений
    MainActivity.kt          — чат, распознавание речи, оркестрация
    CommandEngine.kt         — офлайн-парсер команд (30+ шаблонов)
    GeminiClient.kt          — REST-клиент Gemini (JSON, без библиотек)
    WakeWordService.kt       — фоновая служба «Джарвис» (foreground, mic)
    SettingsActivity.kt      — ключ, модель, тумблеры
    TtsController.kt         — озвучка (TextToSpeech, ru-RU)
    OrbView.kt               — анимированная сфера-реактор (Canvas)
    Prefs.kt, BootReceiver.kt
scripts/
  fetch-toolchain.sh         — скачивание тулчейна из зеркал
  build-apk.sh               — полный оффлайн-пайплайн сборки APK
```

## ⚠️ Замечания

- Требуется Android **8.0+** (API 26). Проверено на targetSdk 34.
- Wake-служба использует `SpeechRecognizer` — на некоторых прошивках сервис
  распознавания недоступен, тогда отключите её (иконка 🎙 в шапке).
- На Android 14 фоновый микрофон-сервис может потребовать ручного запуска —
  просто один раз включите тумблер в приложении.
- Лицензия проекта — **GPL-3.0** (унаследована).
